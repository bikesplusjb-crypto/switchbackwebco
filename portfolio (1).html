CardGauge

A full trading-card market intelligence platform, built from scratch.

CardGauge started as a question — could a single person build a credible, end-to-end product for trading card collectors? The answer turned out to be yes, and the result is in production: an AI-powered card scanner that identifies cards from a phone photo, real sold-price comps from completed sales, a transparent grading decision tool, a hot/cold market tracker, a Pokémon-specific section, and a Cards-vs-Wall-Street feature that compares card returns to real stocks.

The app runs at app.cardgauge.com on Render with a Supabase database and accounts, backed by a custom Node/Express API wired to OpenAI Vision, eBay, sold-sales data and Stripe payments. The marketing site sits on Wix. Every feature is real and working — no fake data, no placeholder dashboards, no "coming soon" pages disguised as products.

This is the proof that we can build complex, multi-feature, real-data products solo and keep them running. If we can do that, your small-business site is straightforward.

WorthGauge

A cloud-based collection tracker with user accounts, photo storage, and built-in payments — designed and built end to end.

WorthGauge is a full web application for collectors who want to know what their collection is worth and prove it for insurance. Users create an account, log items across categories — cards, watches, sneakers, coins, art, and more — track values over time, upload photos, and generate an insurance-ready statement, complete with a formal cover sheet and per-item proof-of-ownership records.

Unlike a static website, this is a real software product: secure passwordless login, cloud-synced private user data, private photo uploads, transactional email through a custom-verified domain, and a working paywall that takes real payments. It runs on a Supabase backend with row-level security, is deployed on its own custom domain, and was designed, built, and shipped solo — from the database schema to the engraved visual identity.

This is the upper end of what we can build: not a brochure site, but a functioning, account-based, payment-enabled product. If your business ever needs more than a website — a tool, a portal, something that actually does something — this is the proof we can build it.

HotWheelsGauge

A live market-value tool for vintage Hot Wheels — built as a working car dashboard you can read at a glance.

HotWheelsGauge answers one question for diecast collectors: what is this casting actually worth right now? Type in any Hot Wheel — a Redline, a Treasure Hunt, a Super Treasure Hunt — and the tool pulls live eBay listings and sold comps in real time, then reads the result back through a full instrument cluster: twin RARITY and VALUE gauges whose needles physically swing to the car's tier and price band, with a center digital display that locks onto the result.

Around the lookup sits a complete reference hub — vintage Redline guides, Treasure Hunt identification, and a step-by-step "how to identify what you have" walkthrough. It runs on a custom Node/Express backend deployed to Render, wired to eBay's Browse API, with the whole experience designed as a single immersive dashboard rather than a plain search box.

It's another proof point: a real-data product with a strong, specific personality, designed and shipped solo for a niche audience that nobody else was building for properly.
